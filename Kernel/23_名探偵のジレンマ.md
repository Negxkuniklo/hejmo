# 23 名探偵のジレンマ

名探偵のジレンマというものがある。
これは2026年に[Nonna Neĝkuniklo](https://Negxkuniklo.github.io/homepage/)によって提唱された逆説である。

[[20_探偵の思考法|探偵の思考法]]に纏めた通り、かのシャーロック・ホームズは**知識・観察力・推理力**の3要素が探偵に必要な能力だと述べている。
そして帰納と演繹、アブダクションによって推理を行うというわけである。

一般的に、知識・観察力・推理を鍛え、高度な論理的思考ができるようになると、一方で常識の枠組みに囚われ、発想の飛躍をしにくくなる傾向がある。
子どもは、突拍子もないことを考え、実行する姿が良く見受けられる。
しかしこのヒラメキとも言える発想力は、成長し、論理的思考能力が備わるにつれて退化してしまうものである。

しかし、アブダクションの本質は消去法であり、非常識な仮説を形成することこそが、謎を解く鍵である。

つまり、難事件の解決には高度な論理的思考能力が不可欠だが、論理的思考能力が発達・洗練されるほど常識の枠組みに囚われ、発想の飛躍をしにくくなり、かえって事件の解決が困難になるという逆説である。

この名探偵のジレンマを乗り越える、つまり柔軟なヒラメキ力を取り戻すため、
[エバーグリーンノート](https://notes.andymatuschak.org/Evergreen_notes)というノート術を勧める。
具体的には、ObsidianのWikiリンクを有効活用することだ。
[[22_日記を書くこと|日記を書くこと]]に書いたように、私はノートのプロパティに、他のノートのWikiリンクを纏めて書いている。
これによりノート同士が繋がり、大きなヒラメキの材料となるのである。
子どもは数少ない情報を無理やり繋げることで突飛なヒラメキをするが、我々大人は逆により多くの情報を繋げることで、有効的なヒラメキを得ることができるだろう。
